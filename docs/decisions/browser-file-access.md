# 文件访问决策：恢复内置预览，默认定位到 Windows Explorer

日期：2026-10-19。此决定取代此前“文件打开优先使用网页”的方案；此前实现提交为 `c46eaf1`，原内容可从 Git 历史核对。

用户澄清：内部侧栏与 Ctrl+P 已经负责文件浏览；需要的是在 HTML 无法看到网页效果、CSV 无法以表格查找时，能通过“打开”和“打开所在文件夹”定位原文件，并用 Windows 软件继续操作。用户明确选择默认打开 Explorer 并选中文件。

因此撤掉自建网页文件查看器、目录浏览、内容路由与文件链接拦截。保留内置预览，默认外部打开和文件管理器目标都通过 WSL 路径转换启动 Windows Explorer；明确选择其他编辑器和远程主机的流程沿用上游。

取舍：不新增与 Ctrl+P 重复的文件系统，不把文件复制到 Windows 下载目录；HTML/CSV 的效果查看交给用户选择的 Windows 工具。内置浏览器完整兼容性和 CSV 表格能力不在本次实现范围内，也不声称已修复。

实现与使用见 [文件访问手册](../file-access.md)，检查与部署边界见 [验证记录](../validation.md)。
